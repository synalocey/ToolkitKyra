🏭 FID & NSR Tracking Dashboard

功能简介
  • 汇总 FID、CTL、NSR 和 NCE / FA，查看 Commit 机台的 Slot 与交付风险。
  • 通过概览和风险定位机台，查看 FID 360° 全方位信息。
  • 批量查询 NSR 的 Cycle Time 与 Workflow 详情。
  • 可在浏览器中为 FID 和 NSR 保存个人标记和 Note，便于持续跟踪。
打开 🏭 FID & NSR Tracking Dashboard ↗

开始使用

打开 Dashboard

方法一 Tampermonkey 菜单

打开任意 Lam Research 页面，点击扩展按钮 → Tampermonkey，选择 🏭 FID & NSR Tracking Dashboard。

方法二 NSR 页面按钮

在 FEP 的 NSR 页面，点击标题旁的 🏭 FID & NSR Tracking Dashboard 按钮。

Data Sources 数据加载

12 FID / CTL BOBJ

自动模式：保持 SAPGUIcontrol.exe 运行，页面自动读取 BOBJ；点击 Update 可以刷新数据。
手动模式：下载 BOBJ 模板，Excel → Analysis → Refresh 后上传。

3 CTL-NSR List

预载 CTL 系统的历史数据，可用 Append 追加最新 CTL List。

4 NSR Log

自动从 NSR 系统读取近一年的记录，点击 Load NSR 可修改日期范围。

5 NCE / FA

预载历史数据，可通过 Import 手动导入最新数据。

Filters 筛选与搜索

在左侧 Search FIDs, CTLs, or NSRs 中快捷筛选，可一次输入多条编号；仅输入一个 FID 或 CTL 时，点击右侧 🔍 可打开 FID 360°。

Account、Assessment Quarters、Current Quarter、Customer 等可按需筛选。同一筛选内取并集，不同筛选取交集。

页面上方的 Filtered By 显示已有筛选条件，可以点击进行快速定位或者删除筛选条件。默认筛选当前及后续 4 个财务季度，CTL Type 默认筛选 Slot / Config / Drop Slot。

FID 查询

查看 FID Overview

加载 FID Database 后，可进入 FID Portfolio 标签页。

FID Overview 展示 Total FID、No Slot 和 Slotted FID。Slotted FID 包括已有效批准 Slot 及随后 Drop Slot 的机台；No Slot 包括尚无有效 Slot 历史的机台，含首次 Slot 待批准。Slotted FID 下方的 drop slot 数量已包含在总数中，点击可筛选。

Slotted FID 按横轴 Pre-slot Risk 和纵轴 Post-slot Risk 两个维度展示。Pre-slot：普通 Slot 提前超过 20 周为 Stable，不超过 20 周为 Late；No Labor 提前超过 12 周为 Stable，不超过 12 周为 Late。Post-slot 根据已批准的 Config CTL 分为 Late CTL 和 Stable CTL。

对于 Slotted FID，出现 Late Slot 或 Late CTL，记为 Risk FID；两个维度均稳定时记为 Stable Slot & CTL。点击任意卡片可筛选出对应状态的机台，并在下方 FID Details 查看列表。

Risk Drivers 板块还列出其他异常或待跟进的 FID，可点击相应项目筛选。例如 Pending NSR 表示尚未完成的请求，不区分提前周数，也不影响 Slot / CTL 稳定性。

FID 列表和 FID 360° 全方位信息

通过 FID Overview 卡片或侧边栏 Filters 筛选后，可在 Interactive Pivot 查看透视结果，在 FID Details 查看 FID 列表。

在 Interactive Pivot 部分，透视图的 Current Quarter 按当前排期将每个 FID 计入一个季度；点击数量可筛选相应结果。

在 FID Details 部分，点击 FID 列表首列可切换 ⊘ Ignore / ★ Star 标记，点击 Note 添加个人备注；标记和备注仅保存在本地电脑中。在 FID Overview 图右上角勾选 ☐ Exclude ignored FID/NSR，可以从统计与明细中排除所有 Ignore 条目。点击 FID 编号，可查看对应 FID 的全方位信息，包括机台概况、交付风险及 NSR、CTL 历史等。

CTL 可通过 Change Summary 与 NSR 建立关联，引用编号后会标注 (Chg)；鼠标悬停在 NSR 或 CTL 记录上时，关联记录会以蓝色实线框标记。仅在 Notes / Root Cause 中提及的 NSR 只显示编号，关联记录则以蓝色虚线框标记。

CTL 查询

进入 Slot / CTL 标签页，CTL Overview 按 Stage 分为 Completed、In work、Draft、Rejected 和 Cancelled。点击状态卡片可进行筛选。下方 Interactive Pivot 可查看透视结果。

最下方 CTL Details 显示 CTL 的 Stage、类型、创建及批准日期、Initiator 和 NSR Reference 等信息；Elapsed Days 显示 In work 的 CTL 自创建以来经过的天数。

点击 CTL 编号可在 CRM ↗ 中打开详情，点击 FID 或 NSR 编号可以在 FID 360° 中查看 FID 和 NSR 的详情。

NSR 查询

查看 NSR Overview

加载 NSR Log 后，可进入 NSR List 标签页。所有 NSR 按状态分为 Completed、In workflow、Rejected 和 Cancelled，点击状态卡片可筛选记录。

Completed 细分为 Completed NSR but no CTL、CTL pending approval、CTL approved 和 Completed 5D NSR。

NSR 列表与明细

通过 NSR Overview 或 Filters 筛选，在 Interactive Pivot 查看透视结果，在 NSR Details 查看列表。

点击 NSR 编号会打开 FID 360°，点击 CTL references 中的编号可定位到对应的 Slot / CTL History 记录。在 NSR History 再次点击 NSR 编号可查询单条 Cycle Time 与 Workflow；也可通过 NSR Details 表格右上角的 Cycle Time 批量查询当前显示的全部 NSR。

NSR Cycle Time 与 Workflow

1 查询 NSR

自动查询：从 NSR Details 或 FID 360° 带入的编号会自动查询和展示结果。
手动查询：进入 NSR Cycle Time 标签页，每行输入一个 NSR 编号，点击 Query。

2 查看 Workflow 明细

查看 Assigned Approver、Pending Days 和 Cycle Time；点击 NSR# 打开 Workflow Detail，通过 NSR ↗ 进入原始 NSR 页面。

3 复制与导出

点击 Copy 复制当前结果，或用 Export XLSX 将 Cycle Time 与 Workflow 明细导出到 Excel。

汇总与导出

查看 Summary Metrics

进入 Summary Metrics 标签页，对比当前筛选范围内的 Slot Completion%, Slot Stability%, FID, NSR 等指标。

Group by 默认 Assessment Quarters：按当前及历史季度分别统计，同一 FID 可出现在多个季度。也可修改成按照 Current Quarter、Account 等其他类别进行展示。

复制与导出

各表格右上角的 Copy 可复制当前结果，Export XLSX 可导出 Excel。

在 Rules & Settings 中，使用 Export Settings 备份自定义设置，包括 FID / NSR 标记和 FID 备注等；使用 Import Settings 恢复，导入时会替换现有设置。

SAP Toolbox

功能简介
  • 批量导出 ZBOM PDF，支持自定义文件名
  • 按组比较 ZBOM，标出配置与 Gas 差异并导出 Excel
  • 基于 Reference Quotation 创建新的 Quote
打开 SAP 工具箱 ↗

如何打开 SAP 工具箱

打开任意 Lam Research 页面，点击扩展按钮 → Tampermonkey，选择 🧰 SAP Toolbox。

连接 SAP GUI

1 首次下载 SAPGUIcontrol

首次使用时，在 SAP Toolbox 点击 Download SAPGUIcontrol，下载并解压。

2 运行并最小化

运行 SAPGUIcontrol.exe 并最小化，保持程序运行，SAP Toolbox 会自动连接。

3 选择 SAP 窗口

登录 SAP GUI 后，SAP session 默认选择第一个可用窗口进行自动化操作。
多个任务同时运行时，先在 SAP 打开多个窗口，再为各任务选择不同窗口。

刷新 FID BOBJ Data（可选，建议）

1 刷新数据

点击 Update 并稍等，工具会刷新 FID BOBJ Data，用于后续导出文件的命名等功能。

2 打开查看

数据以 BOBJ_FID.xlsm 保存在本机，点击 Open 查看 FID BOBJ 内容。

批量导出 ZBOM PDF

1 输入 Quotation

选择 ZBOM PDF 标签，在 Quotation Data 中每行输入一个 Quotation，即可批量导出。
也支持粘贴 Excel 多列数据，可包含 FID、System Description 等信息。History 可恢复最近运行的输入。

2 设置文件名

在 Filename 设置模板，点击下方字段按钮插入变量，在 Preview 中确认文件名。
（{FID}、{System Description} 在 Preview 中可能暂不完整，确保 FID BOBJ Data 是最新，导出完毕后会自动补全）

3 导出与查看结果

点击 Start PDF Export，工具会自动操作所选 SAP 窗口并批量导出 PDF，完成后点击 Open Folder。

比较 ZBOM

1 输入 Quotation

选择 ZBOM Compare 标签，在 Quotation Data 中每行输入一个 Quotation，也可从 Excel 粘贴含 FID 的多列数据。

2 设置文件名

在 Filename 设置模板和连接文字（默认 vs），在 Output Folder 设置导出目录。

3 设置比较分组

在 Compare Group 中，将需比较的 Quotation 设为同一组；选择 Standalone 时仅整理该 Quotation，不参与比较。

4 开始比较并查看结果

点击 Start Compare，在 G01 等页签查看比较结果，差异以底色标出；有 Gas 数据时提供 Gas 比较表。

创建 Quotation

1 填写 Reference Quotation 和 FID

选择 Quote Create 标签，填写 Reference Quotation，在 FID 中每行输入一个 FID 即可。
也可一并粘贴 CRD 和 ValidTo，缺少 CRD 时会从 FID BOBJ 补全，也可在 Preview 中修改。

2 检查日期与 Version

Default ValidTo 默认为今天起 30 天，New FID suffix 默认为 -01，表示新建的 Quotation 名称格式为 XXXXXX-01。
FID 与 Reference Quotation 相同时，Version 后缀会自动 +1，并沿用其 CRD。

3 填写到 SAP 并继续

点击 Create Quote 后，工具会使用 ZVA21M 填写数据，随后需在 SAP 中自行检查并手动完成创建。

查找与 TM/PCN 等相关的 Part Changes

功能简介
  • 对比任意两份 SO/Quote BOM，提取 Delta Part Number。
  • 匹配 Tech Memo、PCN 等技术文档，识别哪些 Part Change 与文档发布的变化有关。
打开 Tech Articles ↗

筛选对应机型的技术文档

准备待比较的 BOM，确认机型后按照 System 筛选，获取该机型的全部 Tech Articles。

点 Apply Filters → 🔩 Find Part Changes Related to TM/PCN，等待全部 Part Number 读取完成。

上传 BOM 并匹配

上传两份 SO/Quote BOM，点 Find Tech Articles for BOM，系统会自动检索 Delta Parts 及其对应的 Tech Articles。

（已 Shipped 或已 Slot 的机台可用 SO BOM；未 Slot 的 Draft 可用 Quote BOM。）

查看匹配结果并导出

点击文档标题，确认哪些 Delta Parts 与文档发布的变化有关；点 Download Excel 导出匹配结果和两份 BOM。
