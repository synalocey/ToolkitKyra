在 Edge 中完成安装

第一步：安装 Tampermonkey

点击下面的按钮，打开 Edge 扩展商店。

打开 Tampermonkey 商店页面 ↗
  1. 在商店页面点击 获取（Get）。
  2. 在确认窗口点击 添加扩展（Add extension）。
  3. 等待安装完成，然后返回本页面。

如果商店按钮显示 Remove（移除），说明已经安装，可以直接继续。

已经安装过的用户也点这里。

第二步：允许脚本运行

复制下面的地址，然后在 Edge 中按 Ctrl+T 新建标签页，粘贴到新标签页的地址栏后按 Enter。

  1. 在左下角找到 开发人员模式（Developer mode），把开关打开。
  2. 在右侧找到 允许用户脚本（Allow user scripts），把开关打开。
  3. 两个开关都打开后，继续下一步。

需要图示？查看 Tampermonkey 官方说明 ↗

第三步：安装 Toolkit Kyra 脚本

点击下面的按钮，Tampermonkey 会显示脚本安装页面。

打开脚本安装页面 ↗
  1. 点击 安装（Install）；如果之前安装过，可能显示“重新安装”或“更新”。
  2. 最后，打开 NSR Tracking Dashboard，如果显示正常则安装成功，可以关闭此教程页面。
